Each parser has a stance file, which records its positions on features and on known areas of divergence. The columns of the tables below use these words:

  • valid, invalid: whether the corpus grammar accepts the document.
  • settled: a rule the specification settles beyond the grammar, such as an alias naming no anchor or a key written twice.
  • as declared: the stance file declares that the parser refuses a feature the document carries.
  • after the parse: the parser's composer or loader rejects a document the corpus vouches for in syntax only. The report does not score these.
  • explained: a departure in the stance file matches the document. A departure is a position the parser takes, a leniency, or a known defect.
  • tagged: the document carries a tag marking a question the specification leaves open, and the stance file declares no stand on it.
  • a column with none of these words counts cases nothing explains: each is a defect in the parser or in the corpus.
