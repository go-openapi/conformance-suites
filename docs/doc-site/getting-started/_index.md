  Two routes into a corpus: read the file from any language, or use the Go API.

A conformance suite is a corpus of test cases, published as a single file.
You can read it with any JSON reader and a base64 decoder, and score your parser, written in any language.

Go users can also import this module, to run the oracles or the generators, or to load the small corpus
embedded in the module without downloading anything.
