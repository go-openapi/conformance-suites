description: |
  Two routes into a corpus: read the file from any language, or use the Go API.
---

A corpus is a file first. Read it with any JSON reader and a base64 decoder, and score your parser in the
language it is written in. The Go packages are a second route, for Go users who want the oracles, the
generators, or a corpus embedded in the module.
